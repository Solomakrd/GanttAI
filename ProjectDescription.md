### Задача
Пользователь открывает веб-страницу и сразу видит интерактивную диаграмму
Гантта с загруженными тестовыми данными (засидированными). Также можно
загрузить свой Excel со списком задач.
Рядом с диаграммой — чат, через который можно на естественном языке массово
редактировать план: переносить задачи, менять зависимости, добавлять новые,
перераспределять исполнителей. Изменения от агента мгновенно отражаются на
диаграмме.
По клику на задачу открывается модалка с деталями — что именно показывать
внутри, решаете сами.
План можно экспортировать обратно в Excel.

### Обязательный стек
- Фронт: React
- Бэк: Python / FastAPI
- MCP
- LLM через API

### Формат входного Excel
Колонки: задача, описание, исполнитель, длительность, предшественники.
