# Файлы для ручной проверки импорта

Выберите файл в блоке **Excel exchange**, укажите дату в календаре и нажмите **Import plan**.
Для сравнения результатов используйте дату **02.10.2026 (пятница)**.

## Успешная загрузка

| Файл | Что проверяет | Ожидаемый результат |
|---|---|---|
| `01-simple-chain.xlsx` | Три последовательные задачи, учёт выходных | «Сбор требований» 2–4 октября, «Разработка» 5–8 октября, «Проверка» 9–10 октября |
| `02-parallel-project.xlsx` | Восемь задач, параллельные ветки, несколько предшественников, ссылки на последующие строки | Задачи отображаются в порядке строк; «Запуск» — 16 октября, после завершения всех веток |
| `03-names-with-punctuation.xlsx` | Названия с запятыми и кавычками, CSV-список предшественников внутри ячейки | Три задачи; «Согласование» начинается 5 октября. Кавычки в ячейке предшественников — часть формата, не ошибка |
| `04-preserved-dates.xlsx` | Дополнительные колонки `id`, `start_date`, `end_date` | Даты 2–4, 8–9 и 12 октября 2026 сохраняются даже при выборе другой даты в календаре; промежутки не исчезают |

После успешного импорта нажмите **Export Excel**, затем импортируйте скачанный файл с другой выбранной датой. Названия, исполнители, зависимости и сохранённые даты должны остаться прежними.

## Ожидаемые ошибки

Сначала загрузите любой корректный план. При загрузке каждого файла ниже приложение должно показать ошибку и **сохранить прежнюю диаграмму**.

| Файл | Ожидаемый результат |
|---|---|
| `05-error-duplicate-names.xlsx` | Повтор названия «Анализ» после удаления пробелов; в сообщении указаны строки 2 и 3 |
| `06-error-unknown-predecessor.xlsx` | Не найден предшественник «Несуществующая задача», строка 3 |
| `07-error-cycle.xlsx` | Обнаружен цикл «Анализ → Разработка → Проверка → Анализ» |
| `08-error-duration.xlsx` | Нулевая длительность в строке 2; требуется положительное целое число |

Все файлы используют первый лист и русские заголовки. В колонке «предшественники» записаны названия задач. После обновления страницы приложение возвращает исходный тестовый план.
